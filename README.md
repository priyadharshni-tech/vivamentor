# VivaMentor AI — 6-Agent Multi-Agent Platform

VivaMentor AI is an AI-powered multi-agent career preparation platform that helps students prepare for technical vivas, coding interviews, resume ATS optimization, HR interviews, research projects, and complex CS concepts.

## 🚀 Key Features

### 🎓 1. VivaMentor — AI Mock Viva Examiner
- Intelligent mock viva examinations with department, subject, topic, and difficulty selection.
- Dynamic follow-up questions based on student answers.
- Voice dictation support via Web Speech API.
- Radar performance scorecard (Correctness, Communication, Confidence).

### 💡 2. ConceptGuru — Technical Concept Explainer
- Real-world mental analogies for complex computer science topics.
- Dynamic SVG visual flowchart diagrams.
- Monospace code walkthroughs, interactive quizzes, and common misconception detectors.

### 💻 3. CodeDoctor — Code Review & Debugging Expert
- Multi-language support (Java, Python, JavaScript, C++, C).
- Synchronized line numbers with bug line gutter highlights.
- Side-by-side dark-mode code diff comparison.
- Time and Space complexity optimization analysis cards.

### 📄 4. ResumeCraft — Resume Builder & ATS Analyzer
- Drag-and-drop resume upload zone.
- Animated SVG ATS compatibility score gauge.
- Matched vs. missing ATS keyword matrix.
- Quantifiable impact bullet point rewriter (+45% impact boost tracking).

### 🎤 5. InterviewAce — HR & Technical Interview Coach
- Specialized tracks (HR, Technical, Behavioral, Company Specific).
- Live interview room with SVG countdown timer.
- 4-Axis STAR framework evaluation (Situation, Task, Action, Result).
- Multi-turn session performance analytics radar.

### 📚 6. ResearchPilot — Research Paper Assistant
- Literature survey matrix tables (Methodology, Limitations, Key Results).
- Novelty project idea generators for mini and final-year projects.
- Visual project timeline with phase milestones.
- One-click multi-format citation generator (IEEE, APA, BibTeX, MLA).

### ⚡ 7. Supervisor Engine (Multi-Agent Hub)
- Orchestrates multi-agent pipelines (*Placement Readiness*, *Java Interview Prep*, *Final Year Project*).
- Animated SVG workflow pipeline visualization.
- Synthesized multi-agent readiness report with strategic action items.

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: TailwindCSS, Vanilla CSS Design Tokens, Glassmorphism
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Icons**: Lucide React
- **Persistence**: LocalStorage with Activity Tracking

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/priyadharshni-tech/vivamentor.git

# Navigate to project directory
cd vivamentor

# Install dependencies
npm install

# Start local development server
npm run dev
```
